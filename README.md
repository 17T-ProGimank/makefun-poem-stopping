# The Poem About Stopping

A short poem about agency — the power to stop and to stay — written for the
[make.fun bounty](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

`main.py` (Python 3.13, standard library only) writes one deterministic poem
to `/output/entry.txt`: a hand lifting a kettle off the heat before it
whistles, a cursor blinking, a door left open — stopping as an act, and
staying as a choice.
